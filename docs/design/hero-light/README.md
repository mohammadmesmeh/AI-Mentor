# Home hero — light brand version (design reference)

Visual reference only. Rebuild with the project's components, Tailwind
tokens and next-intl. Do not copy the markup.

- ExactHero.dc.html   → the hero. Open the file: texts for English AND
  Arabic are in the script at the bottom (renderVals); `lang` switches.
- ExactHeroAR.dc.html → the Arabic (RTL) instance of the same file.

Key measurements are inline in the markup (sizes, colors, spacing).
The background art (waves, swoosh lines, gradient logo mark) is one
inline SVG; in RTL the whole SVG is mirrored (scaleX(-1)).
The bottom strip's numbers and texts are SAMPLE data ("Example").
